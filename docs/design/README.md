# Design

Mockups for the first version. I drew the screens on paper first, then had an AI tool
turn the sketches into these SVGs and a style guide, so I'd have something cleaner to
look at while coding. They're a reference, not a spec: the app already drifts from them
in places.

- [wireframes.svg](wireframes.svg) — low-fi layout of Home, Shopping and Settings
- [high-fidelity-mockups.svg](high-fidelity-mockups.svg) — the "paper" look, light theme
- [dark-theme-mockup.svg](dark-theme-mockup.svg) — the same in dark
- [availability-shopping-flow.svg](availability-shopping-flow.svg) — stock mark vs. shopping
- [pwa-install-iphone.svg](pwa-install-iphone.svg), [pwa-install-android.svg](pwa-install-android.svg) — install steps
- [style-guide.md](style-guide.md) — colours, type, components (in Russian)
