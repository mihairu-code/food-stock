# Roadmap

Vertical slices, so every step is already usable.

1. Skeleton: Vite + React + TypeScript, linter, tests, phone-first layout.
2. A local demo storage, so I can build screens without waiting for the backend.
3. Sections and products: add, rename, delete.
4. Stock marks and the computed shopping list.
5. Manual shopping items, section picker on purchase, "make it a staple".
6. Supabase: schema, RLS, sign-in, home and members.
7. Realtime — changes show up for every member without a reload.
8. PWA: manifest, icons, install to the phone.

Later, if it sticks:

- no sign-up at all — email codes on a phone are a pain;
- an account so the home survives a new phone;
- more languages;
- drag and drop for products and sections.
