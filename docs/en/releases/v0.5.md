# v0.5 — Structure and a faster start

**November 12, 2026**

No new features for people — this release is about the code and the first seconds after
launch.

## What changed for people

- **Faster start.** The app shows what it had last time right away and refreshes in the
  background, instead of "Loading…". The home's data is requested together with the list
  of homes, not after it. The connection to the server opens while the app is still
  loading.
- Messages and confirmations are a bit clearer (deleting a section says how many products
  go with it and how many of them were on the shopping list).
- Sign-out moved to the bottom of the settings.

## What changed in the code

- Mutations moved out of screens into `data/hooks`; one-off actions go through
  `useAction`. See [decision 0007](../decisions/0007-tanstack-query-not-rtk.md).
- Toasts are a plain `notify()` function.
- All sheets are rendered by one `SheetHost`; a screen calls `openSheet(...)`.
- One component per file; settings are split into groups; shared `TextField`,
  `SettingRow`, `SettingsGroup`, `SummaryBar`, `Notice`…
