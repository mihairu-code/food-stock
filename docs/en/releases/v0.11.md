# v0.11 — App icon

**November 19, 2026**

## What's new for people

- **Pick your own icon** in settings, under "App": seven options, including dark ones.
  The browser tab icon changes right away.
- On the Home Screen the icon changes only if you **add the app again**: iPhone takes the
  icon at the moment of "Add to Home Screen" from Safari, Android at install or on a
  scheduled re-check. The settings say so right under the choice.
- **"Copy app link"** right there — to paste it into Safari and add the app again.

## What changed in the code

- `shared/lib/appIcons.ts` — the list of icons and their file paths; `vite.config.ts`
  reads it too and builds a separate manifest per icon with one shared `id`.
- The default icon stays in the root of `public/` under its old names: installed apps
  point there.
- The icon set and `scripts/make-app-icons.mjs` were generated with an AI assistant from
  a reference and reviewed by hand.
- `copyLink` is shared by the invite and the app link.
