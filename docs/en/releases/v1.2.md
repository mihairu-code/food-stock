# v1.2 — Home search

**November 2026**

## What's new for people

- **A search button by the tab bar.** With 12 or more products at home, a search button
  appears on Home to the right of the tabs. Tapping it folds the tabs into the Home
  button and stretches the search button into a field above the keyboard. The keyboard
  opens straight away.
- **Search as you type, across all sections.** `ё` and `е` are the same letter, and
  Latin diacritics don't matter: `pho` finds "Phở bò". The matching part of the name is
  highlighted, and folded sections with matches open.
- Everything works in the found rows except dragging: dot, plus, swipe, undo.
- **Nothing found:** "Add «…»" opens the add sheet with the name ready. Once added, the
  new product shows up in the results.
- **Close the search** with the Home button, the cross, `Esc`, or by switching tabs. The
  list goes back to where it was before the search. On a computer, `/` opens the search.
- Screen readers announce how much was found: "3 items found", "Nothing found".
- On a 320-wide screen the tab buttons got slightly smaller to fit the search button in
  the row. With a large browser font the row no longer runs off the edge.

## What changed in the code

- A new slice, `features/home-search`: `matchProductsByName` with tests, the search
  state and the `HomeSearch` component —
  [decision 0019](../decisions/0019-home-search-at-the-bottom.md).
- `--tab-size` is computed from the column width (44px to 3.625rem). New tokens:
  `--tabs-column`, `--tabs-inline`, `--tabs-gap` and `--search-motion`.
- `keyboard.ts` checks the position not only of the sheet but of any element with
  `data-keyboard-anchor`. The miss is computed by `anchorMiss`, which has a test.
- `SheetRequest` for `add-product` takes a `name`.
- `ListRow` highlights the match (`highlight`). There's now a `.sr-only` class.
- `useTabScrollMemory` takes `scrollOf`: Home with the search open is remembered with
  the scroll from before the search.
