# План

Порядок — вертикальными срезами: чтобы каждым шагом уже можно было пользоваться.

1. Каркас: Vite + React + TypeScript, линтер, тесты, раскладка под телефон.
2. Локальное демо-хранилище — чтобы делать экраны, не дожидаясь бэкенда.
3. Разделы и продукты: добавить, переименовать, удалить.
4. Наличие и вычисляемый список покупок.
5. Ручные покупки, выбор раздела при покупке, «сделать постоянным».
6. Supabase: схема, RLS, вход, дом и участники.
7. Realtime — изменения у всех участников без перезагрузки.
8. PWA: манифест, иконки, установка на телефон.

Потом, если приживётся:

- вход без регистрации — почта на телефоне неудобна;
- аккаунт, чтобы не терять дом при смене телефона;
- несколько языков;
- перетаскивание продуктов и разделов.
