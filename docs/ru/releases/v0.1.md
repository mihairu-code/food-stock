# v0.1 — MVP

**8 ноября 2026**

Первая версия, которой можно пользоваться дома.

## Что умеет приложение

**Дом.** Свои разделы — сворачиваемые карточки с продуктами. У продукта название,
эмодзи и вид: *постоянный* или *разовый*. Отметка справа — есть ли он дома.
Закончившийся постоянный продукт остаётся в разделе, приглушённый, и появляется
в покупках. Разовый существует, только пока он есть, — его «закончилось» просто
убирает продукт. Сверху видно, сколько продуктов дома.

**Разделы.** Создать с названием и иконкой, переименовать, удалить. Раздел с продуктами
сначала спрашивает подтверждение — продукты удалятся вместе с ним, и из покупок тоже.

**Покупки.** Один список: закончившиеся постоянные продукты (с разделом, где они живут)
и позиции, добавленные вручную. «Куплено» у постоянного возвращает его домой.
«Куплено» у ручной позиции спрашивает, в какой раздел положить и сделать ли постоянной.

**Удаление.** Свайп строки влево. С мышью и клавиатурой — кнопка, которая появляется
при наведении и фокусе.

**Настройки.** Тема (как на устройстве, светлая, тёмная). С Supabase: участники,
приглашение по почте, отзыв приглашения, удаление участника, выход. В демо-режиме —
сброс примеров.

**Вход и дом.** Одноразовый код из письма, без паролей. При первом входе — принять
приглашение или завести свой дом. Изменения других участников приходят сами.

**PWA.** Ставится на экран «Домой», оболочка приложения кешируется.

## Известные ограничения

- Вход по коду из письма на телефоне неудобен: переключиться в почту, скопировать,
  вернуться.
- Встроенная почта Supabase доходит только до участников организации в Supabase.
- Каждое действие ждёт ответа сервера, прежде чем экран обновится.
- Нельзя положить в покупки то, что ещё есть дома.
- Убрать постоянный продукт из покупок можно только удалив сам продукт.
