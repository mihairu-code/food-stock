# v0.11 — Иконка приложения

**19 ноября 2026**

## Что нового для людей

- **Свою иконку можно выбрать** в настройках, в разделе «Приложение»: семь вариантов,
  включая тёмные. Значок вкладки браузера меняется сразу.
- На экране «Домой» иконка поменяется, только если **заново добавить приложение**:
  iPhone берёт иконку в момент «На экран „Домой“» из Safari, Android — при установке или
  плановой проверке. Об этом прямо сказано под выбором.
- **«Скопировать ссылку на приложение»** рядом — чтобы вставить её в Safari и добавить
  приложение заново.

## Что изменилось в коде

- `shared/lib/appIcons.ts` — список иконок и пути к их файлам; его читает и
  `vite.config.ts`, который собирает отдельный манифест на каждую иконку с одним `id`.
- Иконка по умолчанию лежит в корне `public/` под прежними именами: на них ссылаются
  уже установленные приложения.
- Набор иконок и скрипт `scripts/make-app-icons.mjs` сгенерированы с помощью ИИ по
  образцу и вычитаны вручную.
- `copyLink` — общий для приглашения и ссылки на приложение.
