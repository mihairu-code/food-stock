# v0.3 — Аккаунт Google

**10 ноября 2026**

## Что умеет приложение

Всё из v0.2, плюс:

**Экран приветствия.** Новый человек выбирает: войти через Google или продолжить без
аккаунта. Пока вход через Google на сервере не настроен, экрана нет — приложение
стартует как в v0.2.

**Google из настроек.** Кто уже пользуется приложением без аккаунта, может войти через
Google в Настройки → Аккаунт. Всё, что он завёл, переходит в аккаунт.

**Один человек — один аккаунт.** Вход на устройстве, где уже есть анонимный
пользователь, вливает его в аккаунт: дома переходят, дубли исчезают, анонимный
пользователь удаляется. На втором устройстве того же человека лишний участник просто
пропадает.

**Выбор дома.** Если и на устройстве, и в аккаунте есть дома с данными, приложение
спрашивает, какие оставить, и прямо пишет, что будет с другими: удалятся вместе
с данными или — если там живут другие люди — вы просто из них выйдете.

**Кто есть кто.** У участника видна почта аккаунта, а без аккаунта — устройство, с
которого он заходил: «Safari · iPhone», «Приложение · iPhone».

**Приглашение переживает Google.** Открыл ссылку-приглашение, вошёл через Google —
и всё равно попал в этот дом.

## Известные ограничения

- Выйти из аккаунта пока нельзя.
- Убрать постоянный продукт из покупок по-прежнему можно только удалив его.
- Только русский язык.
