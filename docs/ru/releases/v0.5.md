# v0.5 — Структура и быстрый запуск

**12 ноября 2026**

Новых возможностей для людей нет — эта версия про код и первые секунды после запуска.

## Что изменилось для людей

- **Быстрый запуск.** Приложение сразу показывает то, что было в прошлый раз, и обновляет
  данные в фоне, а не висит на «Загрузка…». Данные дома запрашиваются вместе со списком
  домов, а не после него. Соединение с сервером открывается, пока приложение ещё
  грузится.
- Сообщения и подтверждения чуть понятнее (удаление раздела говорит, сколько продуктов
  уйдёт вместе с ним и сколько из них было в покупках).
- Выход из аккаунта переехал вниз настроек.

## Что изменилось в коде

- Мутации переехали из экранов в `data/hooks`; разовые действия — через `useAction`.
  См. [решение 0007](../decisions/0007-tanstack-query-not-rtk.md).
- Тост — обычная функция `notify()`.
- Все шторки рисует один `SheetHost`; экран вызывает `openSheet(...)`.
- Один компонент — один файл; настройки разбиты на группы; общие `TextField`,
  `SettingRow`, `SettingsGroup`, `SummaryBar`, `Notice`…
