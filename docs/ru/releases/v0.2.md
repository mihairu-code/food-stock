# v0.2 — Без регистрации

**10 ноября 2026**

## Что умеет приложение

Всё из v0.1, плюс:

**Без регистрации.** При первом запуске незаметно создаются пользователь и дом
«Наш дом». Ни почты, ни кодов, ни экрана входа.

**Ссылки-приглашения.** Владелец в настройках нажимает «Пригласить по ссылке» и получает
ссылку, которой можно поделиться или скопировать. Срабатывает один раз, живёт 7 дней,
показывается только при создании. Неиспользованные ссылки видны со сроком и
отзываются.

**Вступление.** Открыл ссылку — ты в доме. Если приложение уже стоит на экране «Домой»,
ссылку вставляют в нём: Настройки → «Присоединиться по ссылке». Пустой дом, созданный
при первом запуске, исчезает после вступления в чужой.

**Участники.** Необязательное имя, его видят остальные. Владелец удаляет кого угодно,
кроме себя.

**Иконка по названию.** Подсказки меняются, пока набираешь название, — два ряда, за край
экрана ничего не вылезает. «молоко 3,2%» даёт 🥛 и другую молочку, «сухарики» —
🥨 🍟 🥜 🍿. Прощает опечатку. Уверенное совпадение подставляется само, ручной выбор
главнее.

**Мгновенные правки.** Разделы, продукты и покупки появляются сразу, запрос уходит
следом. При ошибке правка откатывается, тост объясняет почему. Короткие тосты
подтверждают действия.

**Переходы.** Экран мягко появляется при смене вкладки, разделы плавно сворачиваются.

**Выложено** на Vercel. Автоматизированные браузеры (превью ссылок, поисковики,
e2e-тесты) видят демо и не заводят настоящих пользователей; сайт скрыт от поиска.

## Известные ограничения

- Пользователь живёт на одном устройстве: почистил данные сайта или сменил телефон —
  дом для этого человека потерян (если не пригласить заново).
- У Safari и приложения на экране «Домой» на iPhone раздельные хранилища.
- Убрать постоянный продукт из покупок по-прежнему можно только удалив его.
- Только русский язык.
