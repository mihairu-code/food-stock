# v1.3.1 — Перед запуском: выход из дома и анимация загрузки

**Ноябрь 2026**

## Что нового для людей

- **«Покинуть дом».** В настройках, в группе «Дом», с подтверждением: доступ к дому
  пропадает, вернуться можно только по новой ссылке. Уходит владелец — владельцем
  становится тот, кто в доме дольше всех, и подтверждение его называет. Дальше
  открывается другой дом, а если других нет — новый пустой. Единственный участник строки
  не видит, в демо-режиме её тоже нет.
- **«Вас удалили из дома „…“».** Раньше, если владелец удалял участника, приложение молча
  открывало другой дом или создавало новый пустой. Теперь оно говорит, что случилось, —
  и если удалили, пока приложение было закрыто.
- **iPhone и iPad: сначала войти, потом ставить на экран «Домой».** В браузере без
  аккаунта, когда в доме уже есть продукты, в настройках над кнопкой «Войти через Google»
  стоит строка «Дом хранится в Safari: приложение с экрана „Домой“ его не увидит». У
  установленного приложения своё хранилище, и без входа оно открылось бы с пустым домом.
- **Второй раздел с тем же названием не создаётся**, как и продукт: поле встряхивается,
  подпись «Такой раздел уже есть». Сменить у раздела только иконку можно.
- Названия сравниваются без разницы между «ё» и «е»: «Мёд» и «Мед» — один продукт.
- **Загрузка с картинкой.** Вместо строки «Загрузка…»: при запуске приоткрывается
  холодильник, на «Доме» продукты встают на полки, в «Покупках» отмечается список.
  Картинка появляется через 300 мс, поэтому быстрая загрузка не мелькает. С системной настройкой
  «Уменьшение движения» картинка стоит и тихо мерцает.

## Что изменилось в коде

- Миграция `0013_leave_household`: `public.leave_household(p_household_id)` поверх
  `private.leave_home`; последнему участнику отказывает —
  [решение 0022](../decisions/0022-leave-home.md). Метод хранилища `leaveHousehold`,
  `useLeaveHousehold` и `leftHouseholdSelf` в `entities/household`, `nextOwner` в
  `entities/member`, строка `LeaveHomeRow` в настройках.
- `HouseholdGate` помнит открытый дом и, когда тот пропадает из свежего списка не из-за
  своего выхода, показывает тост `toast.removedFromHome` (`removedHome`).
- `SectionSheet` отклоняет дубль через `findNamed` и `useFieldError`; `normalizeName`
  приравнивает «ё» к «е».
- `StatusNote` получил `loading: 'fridge' | 'shelves' | 'list'`, `role="status"` и
  картинку `LoadingPicture` (встроенный SVG, `aria-hidden`); токен `--loading-size`.
  Ошибки загрузки остаются текстом.
- `useCollapsedSections(sections)`: запись в `try`, id удалённых разделов убираются при
  сохранении, если дом один (список общий для всех домов устройства). В `try` также
  чтение и запись в `preferredHousehold`, `userName`, `inviteToken`, `useProfileSync` и
  удаление билета слияния; `saveMergeTicket` бросает намеренно.
- Порядок выкладки: сначала миграция 0013, потом слияние в `main`.
