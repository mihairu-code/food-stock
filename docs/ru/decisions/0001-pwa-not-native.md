# 0001. PWA, а не нативное приложение

**Статус:** принято · ноябрь 2026

## Контекст

Нужно приложение на телефоне у 2–4 человек: у кого-то iPhone, у кого-то Android.
Я фронтендер, React и TypeScript — каждый день. Swift и Kotlin — нет.

## Варианты

- **Нативные iOS + Android.** Лучшее поведение, но два кода, сторы, ревью, аккаунт
  разработчика Apple за деньги. Для домашнего списка — перебор.
- **React Native / Expo.** Один код, но всё равно сборки, сторы и своя экосистема
  компонентов. Время до первого рабочего экрана — заметно больше.
- **PWA.** Обычный сайт, который ставится на экран «Домой». Выкладка — просто деплой.
  Минусы: на iOS урезанные возможности (нет вибрации, своя возня с клавиатурой,
  установка только через «Поделиться»).

## Решение

PWA на React + TypeScript + Vite, `vite-plugin-pwa` для манифеста и service worker.

## Последствия

- Обновления доходят сразу, без сторов.
- Придётся отдельно разбираться с Safari на iPhone — клавиатура, `100vh`, установка.
  Чувствую, это ещё всплывёт.
- Офлайн-редактирование не делаем: кешируем только оболочку.
