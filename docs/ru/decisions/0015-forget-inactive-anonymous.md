# 0015. Анонимные пользователи, которые не заходили год, удаляются

**Статус:** принято · ноябрь 2026

## Контекст

Без регистрации человек — это анонимный пользователь Supabase на одном устройстве
([0003](0003-anonymous-users.md)). Потерял телефон, удалил приложение, очистил данные
браузера — вернуться к нему нельзя, а дом с продуктами остаётся в базе навсегда. Таких
записей со временем будет больше, чем живых.

## Варианты

- **Ничего не удалять.** Просто, но база растёт мусором, а в чужих общих домах висят
  «участники», которых больше нет.
- **Удалять по `last_sign_in_at`.** Анонимный пользователь входит один раз, дальше сессия
  продлевается — дата входа ничего не говорит о том, пользуются ли приложением.
- **Своя отметка визита и удаление по ней раз в сутки.**

## Решение

- `0010`: таблица `private.user_activity` — последний визит. Приложение отмечает его
  (`mark_visit`) при запуске и при возвращении к нему, не чаще раза в сутки с устройства;
  база не переписывает отметку чаще раза в час. Для тех, кто был до миграции, дата не
  «сегодня» (иначе аноним, не заходивший 300 дней, получил бы лишний год), а оценка: по
  сессиям и токенам обновления, затем по последнему входу и созданию.
- `0011`: `private.forget_inactive_anonymous()` — раз в сутки в 03:17 UTC (`pg_cron`).
  Удаляются только анонимные, не заходившие больше года: по визиту, а для старых версий
  приложения — и по продлению сессии. Аккаунты Google не трогаются: человек может войти
  с любого устройства. Одинокий пользователь уходит вместе с домом; из общего дома —
  только он сам, владельцем становится участник, который в доме дольше всех.
- Вызвать удаление из приложения нельзя, а с периодом меньше года функция откажется даже
  при ручном вызове.

## Последствия

- Это единственное удаление без участия человека; правила менять только осознанно.
- Год — с запасом: дачный дом, куда заглядывают летом, не пропадёт.
